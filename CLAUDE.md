# TutorCat

Static site for tutoring and study-destination counseling. Tutor/counselor profiles come from `data/tutors.json`.

- Static HTML/CSS/JS, no build step. Preview: `python3 -m http.server 4173` then open http://127.0.0.1:4173/.
- Update profiles: edit `source/tutors.xlsx` (one row per person, `Status` column gates publishing), run `npm run tutors:update` (import + change summary + tests), commit `data/tutors.json`. `npm run tutors:check` = is the site behind the workbook? `npm run tutors:template` = clean prefilled workbook. Details: `docs/excel-import.md`.
- Tests: `npm test` (Node built-in runner, no dependencies): `data/tutors.json` privacy checks; every local file `index.html` links or `script.js` fetches exists and is published by the deploy workflow; importer/template tests (fixture rows only); i18n (en/ar same keys and `{params}`, complete plurals, no untranslated text or attributes in `index.html`); every location, curriculum and data value has an Arabic label (`tests/regions.test.mjs`).
- Deploy: `.github/workflows/deploy-pages.yml` tests, then publishes only `index.html`, `styles.css`, `script.js`, `i18n.js`, `assets/`, `data/`, `i18n/` to https://f00di.github.io/tutorcat/.
- Translations: `i18n.js` (no dependencies; any page can load it before its own script) + `i18n/<lang>.json` with flat keys. Add a string: put the key in every `i18n/*.json` (plurals are objects keyed one/other, Arabic also zero/two/few/many), then mark HTML with `data-i18n="key"` (`data-i18n-attr="placeholder:key"` for attributes, `data-i18n-html` for our own strings with `<em>`) or call `t("key", { count })` in JS. Data values (subjects, countries, modes) stay English in the data and are shown through `label(kind, value)` (`value.<kind>.<slug>` keys; Gulf places and curricula come from `data/regions.json`). Never translate what tutors or reviewers wrote; emails to the team stay English.
- Arabic / right-to-left: header toggle (`[data-lang-toggle]`), `?lang=ar` links, choice remembered in localStorage. Use logical CSS only (`margin-inline-start`, `inset-inline-end`, `text-align: start`); `--dir` is `1` or `-1` for direction-aware transforms. Arabic letters use IBM Plex Sans Arabic via `--font-arabic`; never letter-space Arabic. Terms: `docs/i18n-glossary.md`; `i18n/ar.json` still needs native-speaker review. Search engines mostly see English: see `docs/arabic-seo.md`.
- Gulf coverage: `data/regions.json` is the one place for Gulf countries, cities and curricula (English + Arabic names, aliases, `permitBadge`). Add a country: append an object to `countries`. Add a city: append to that country's `cities`. Both feed the importer, the template dropdowns and the site's Where filters; no code change. `countries` on a profile means study-abroad destinations, not where the tutor lives (`baseCountry`, `city`, `servesCountries`).
- No invented tutors, stats or testimonials. The catalog facts line, filter chips and country panels are all built from `data/tutors.json`.
- Design: TutorCat teal, Schibsted Grotesk + Figtree (Google Fonts), light and dark mode. Pills for controls, 16px cards, 10px inputs; motion uses custom ease-out curves and respects reduced motion.

## Privacy
- `source/*.xlsx` / `*.xls` are private and git-ignored. Never commit them or copy their private fields.
- `data/tutors.json` is public. Only approved public fields; no private phones, emails, addresses or notes.
